# Laundry Services - Hamburger Menu

## Description

This project is created using HTML and CSS. It is a responsive Laundry Services webpage. In this task, I added a hamburger menu for the mobile view using only CSS without using JavaScript.

## Features

- Responsive webpage
- Flexbox layout
- CSS Variables
- Media Queries
- Hamburger menu for mobile
- CSS :focus pseudo-class

## Technologies Used

- HTML5
- CSS3


## How to Run

1. Download the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
